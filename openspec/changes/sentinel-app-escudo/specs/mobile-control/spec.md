**Migration:** Usar la pantalla Escudo Pasivo para catálogo, objetivo, captura, métricas e historial. Eliminar el flag y las APIs de envío/replay diagnóstico del producto. Mantener pruebas negativas de protocolo en suites de software y la salida serie de firmware sin OLED como funciones independientes.
